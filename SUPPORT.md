# Support

- Use GitHub Issues for reproducible bugs and bounded feature requests.
- Use GitHub Discussions for product questions and host-adapter design.
- Use private vulnerability reporting for security issues.

Before filing a bug, run `npm run validate` and include the redacted output,
Codex version, operating system, plugin version, and whether the transition was
manual compaction, automatic compaction, resume, clear, or subagent handoff.

Never attach raw transcripts, task ledgers, credentials, or private project data.
