# Context Continuity repository rules

- Keep this an installable, local-first Codex plugin, not a memory platform, task manager, planner, permission system, or second Agent harness.
- The shared task-state ledger owns one effective projection. Continuity code may transport, snapshot, validate, and mark freshness, but must not silently rewrite user intent.
- Platform summaries, agent inferences, and imported handoffs are candidates rather than authority. Preserve provenance, supersession, disputes, and uncertainty.
- Hooks are inspectable, fail open, and silent on ordinary turns. Semantic model judgment alone cannot hard-block work.
- Do not persist full transcripts, hidden reasoning, credentials, or raw tool output. Keep state local and task-scoped.
- Do not install, enable, publish, or add this plugin to a marketplace without explicit user authorization.
- Do not claim product efficacy from unit tests, protocol replay, Hook counts, or model-only grading.
