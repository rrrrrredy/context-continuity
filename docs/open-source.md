# Open-source form

Context Continuity is released under Apache License 2.0 with no CLA and no
separate commercial license.

This form fits the product because:

- individual users, Agent vendors, and companies may use, modify, redistribute,
  and ship it commercially;
- the express patent grant is clearer for a state protocol and host adapters
  than a minimal permissive notice;
- downstream integrations are not forced to open unrelated Agent products;
- redistributed copies must retain the license and copyright notices, and
  modified files must identify changes.

MIT was considered but does not contain the same express patent grant. GPL-style
copyleft was not selected because it would create avoidable integration friction
for proprietary Agent hosts and adapters. A source-available license was rejected
because the goal is interoperable, auditable continuity behavior, not usage
restriction.

Contributions intentionally submitted to the repository use the same
Apache-2.0 terms under the license's contribution clause. Product names and logos
are not granted as trademarks.
